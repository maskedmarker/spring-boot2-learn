# spring-boot启动中使用的配置文件


## ConfigFileApplicationListener

```text
public class ConfigFileApplicationListener implements EnvironmentPostProcessor, SmartApplicationListener, Ordered { //... }

在启动类SpringApplication装配application-context过程中,
ConfigFileApplicationListener作为ApplicationListener能被启动类从spring-boot的spring.factories文件中识别到,可以监听启动类装配application-context过程中的事件.
启动类刚实例化一个新的env后,ConfigFileApplicationListener作为ApplicationListener收到ApplicationEnvironmentPreparedEvent消息后,
ConfigFileApplicationListener加载所有的spring.factories文件中的EnvironmentPostProcessor,同时手动将自己也加进入,
然后将这些EnvironmentPostProcessor排序(排在SystemEnvironmentPropertySourceEnvironmentPostProcessor/SpringApplicationJsonEnvironmentPostProcessor/HostInfoEnvironmentPostProcessor后面),
后续让EnvironmentPostProcessor来处理;


ConfigFileApplicationListener
1. 往env中添加RandomValuePropertySource
2. 加载所有spring.factories文件中配置的PropertySourceLoader(用来解析不同类型的配置文件,比如:PropertiesPropertySourceLoader支持properties/xml,YamlPropertySourceLoader支持yml/yaml)
3. 如无用户配置,则从classpath:/,classpath:/config/,file:./,file:./config/*/,file:./config/下面搜寻名为application的文件作为配置文件(至于文件扩展名,根据当前配置的PropertySourceLoader来决定)
```

```text
spring-cloud-context在spring.factories文件中新增了
org.springframework.context.ApplicationListener=org.springframework.cloud.bootstrap.BootstrapApplicationListener


BootstrapApplicationListener于ConfigFileApplicationListener类似,只不过只会去加载文件名为bootstrap的文件作为配置文件(至于文件扩展名,根据当前配置的PropertySourceLoader来决定)
```
